# Contexto: Atividade 03 - Loop de Agentes

Esta pasta contém o projeto desenvolvido para a atividade prática de simulação de interação entre múltiplos agentes de Inteligência Artificial.

## Componentes Principais
- **`multi_agent_sim.py`**: O script principal que orquestra o loop hierárquico entre agentes remotos (Gemini) e agentes locais (Antigravity/Ollama).
- **`reports/`**: Diretório contendo os relatórios estratégicos gerados pelos agentes simulando como alcançar uma utopia (Eco-Sinergia) ou uma distopia (Servidão Algorítmica), validando as diretrizes de passos coerentes, lógicos e justificados.
- **`logs/`**: Transcrições brutas de cada rodada com a contribuição criativa, a crítica sistemática e a síntese coordenadora de cada perfil envolvido no loop de 20 rodadas.
